# 리콜체크 처음부터 구현하기

이 폴더는 완성된 `project_t4`를 그대로 복사해 실행하는 폴더가 아닙니다.
원본 CSV를 직접 확인하고, 전처리부터 SQLite와 조회 화면까지 단계별로 다시 구현하기 위한 작업 공간입니다.

## 시작 순서

1. `notebooks/01_전체_구현_단계별.ipynb`를 VS Code에서 엽니다.
2. 셀을 위에서부터 한 개씩 실행합니다.
3. `data/raw`는 원본 보관용이므로 직접 수정하지 않습니다.
4. 전처리 결과는 `data/processed/processed_data`에 저장합니다.
5. 전처리 결과를 확인한 뒤 `scripts`에서 SQLite 생성 코드를 작성합니다.
6. 테이블 조회가 확인되면 `app`에 Streamlit 화면을 작성합니다.

## 기존 완성 프로젝트와 비교할 위치

```text
C:\dev\project\project_t4
```

완성 프로젝트의 코드와 SQL을 바로 복사하기보다, 먼저 노트북의 각 단계에서 같은 결과가 나오는지 확인하는 것을 목표로 합니다.
